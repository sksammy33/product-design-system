# QA plan

Phase 2 checks structure, links, manifest consistency and scope boundaries only. No runtime tests exist.

Later gates will verify token integrity; source and theme visual fidelity; keyboard/form behavior; automated accessibility; manual screen-reader behavior; responsive content; and a clean consumer install. Record environment, component/source revision, result and unresolved issues.

[Runtime checklist](accessibility/runtime-checklist.md). A placeholder is not a pass. First-five implementation must be stable before the next group starts.
