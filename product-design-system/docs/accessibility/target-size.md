# Target size

Evaluate pointer targets against WCAG 2.2 AA target-size requirements: generally at least 24 by 24 CSS pixels, with defined spacing and other exceptions. Assess the actual interactive area, not only the visible icon.

Keep intended sizing from Figma. If a target fails and no applicable exception resolves it, document the issue and obtain a design decision before changing geometry. Enlarged hit areas must not overlap neighboring controls.

Record target dimensions, surrounding spacing, any exception relied on, and touch testing evidence.

Reference: [Target Size (Minimum)](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html).
