# Motion

Preserve approved motion specifications when they are available. No timings, easing curves, or motion token values are introduced in Phase 2.

Define reduced-motion behavior before adding animation. Respect the user's reduced-motion preference and keep essential feedback understandable when animation is reduced or removed. Reduced-motion support is a project requirement; it alone does not demonstrate WCAG compliance.

Review auto-moving content, pause/stop controls where required, and flashing risks. Document which effects are essential and test the alternatives in a browser.
