# Normalized token sources

Generated from the immutable raw payloads in `../figma/`; do not edit JSON manually.

DTCG-compatible documents use collection-qualified names, `$type`, `$value` and explicit aliases. Original identities and modes are retained in `$extensions["org.product-design-system.figma"]`.

Shared categories: primitives, typography, spacing, radius, border, effects and motion. Semantic and charts contain Light/Dark files. Theme composition manifests reference the shared and corresponding mode-specific files. Fully assembled DTCG documents are in `../dist/`.

See [package documentation](../README.md) for naming, units, source counts, consumption and regeneration.
