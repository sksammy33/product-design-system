# Button

Action control based on the [current Figma Button set](https://www.figma.com/design/A5R8vBTXZzfV5aj3omQYFG/Product-Design-System?node-id=78-1026) on the [Buttons page](https://www.figma.com/design/A5R8vBTXZzfV5aj3omQYFG/Product-Design-System?node-id=245-343). The component uses native `<button>` semantics. For navigation, render an `<a href>`; a link-like Button variant is only visual and does not change button semantics.

Import `Button` and `ButtonProps` from `@product-design-system/react`, then import `@product-design-system/react/styles.css` once. The stylesheet consumes the generated Light/Dark tokens. Set `data-theme="light"` or `data-theme="dark"` on an ancestor. Provide Geist in the consuming application; Storybook and browser tests load it locally.

Nine variants: `primary`, `secondary`, `tertiary`, `ghost`, `destructive`, `destructive-secondary`, `link`, `destructive-ghost`, `destructive-link`. Sizes: `xs`, `small` (default), `medium`, `large`, `xl`. The public props are `variant`, `size`, `children`, `disabled`, `loading`, `selected`, `leadingIcon`, `trailingIcon`, `iconOnly`, and native button attributes. `selected` is supported on the seven non-Link variants; use it for an actual toggled action. TypeScript rejects `selected` on Link variants. `fullWidth` is absent because the source set has no width property.

Default, Hover, Pressed, Focus, Disabled and Loading are native or derived states. Focus appears on keyboard focus through `:focus-visible`. Loading keeps the original content in layout but hides its pixels, centers a Lucide `loader-circle`, retains the accessible name, sets `aria-busy`, and disables activation. The source has no specified rotation, so the icon is static. `iconOnly` requires an accessible `aria-label` and a single icon child. Decorative leading/trailing icons are hidden from assistive technology. Native `type="button"` is the default; pass `type="submit"` for form submission.

Height/icon pairs follow the five approved Button tokens: XS 28/14, Small 32/16, Medium 40/18, Large 48/20, XL 56/24 pixels. XS/Small use Label Small; Medium Label Default; Large/XL Label Large. Padding uses `spacing.space.*` and the approved Small Button `padding-y` and `icon-gap` tokens. Focus uses `border.strong` and `color.semantic.border.focus`; disabled uses semantic colors and `opacity.disabled`. CSS Modules scope the styles. The library imports only `LoaderCircle` from Lucide; consumers supply their own icon components as props.

Stories: `Components/Button` has a controlled Playground and compact variants, sizes, icons, icon-only, loading, disabled, selected, Light/Dark, long-label and narrow-container views. Run `npm run storybook` from the repository root. Browser tests and Storybook axe checks run with `npm run test:browser`.

Automated axe checks do not establish full WCAG 2.2 AA conformance. Manually test keyboard behavior, focus visibility, screen readers, zoom/reflow, reduced motion and product-specific interaction patterns. The approved Text / Danger token resolves to Red / 700 in Light and Red / 300 in Dark. Destructive Secondary and Destructive Ghost Hover, Pressed and Selected text contrast is 5.88:1 in Light and 7.73:1 in Dark against the current surface token.
