# Assets and provenance

Lucide is the primary icon source. Normally consume Lucide icons from its package rather than copying the whole library into this repository. Package dependencies are deferred to the implementation/tooling phases.

Custom icons and brand assets may be stored here. Verify that package icons match the approved Figma geometry, stroke and intended sizing before use.

For every added asset, record filename, source URL/creator, license or usage permission, version/date, modifications and intended use. Record font provenance too. No asset bytes or third-party license grants are included in Phase 2.
