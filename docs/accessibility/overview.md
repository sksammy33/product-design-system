# Accessibility overview

The Product Design System is created to support WCAG 2.2 Level AA requirements at the design-system level. This is a design intent, not a claim of full WCAG compliance. Application content, implementation, and complete user journeys require separate evaluation.

Figma supplies visual specifications. Semantic behavior must be implemented and verified in a browser. Known contrast, border, and source-reconciliation issues remain open in the [decision log](../decisions/README.md).

All runtime checks are currently **not run**: there is no implemented library in Phase 2. Automated checks will supplement manual keyboard and assistive-technology testing.

Start with the [runtime checklist](runtime-checklist.md). Record evidence and unresolved issues before describing any component as verified.

Reference: [WCAG 2.2](https://www.w3.org/TR/WCAG22/).
