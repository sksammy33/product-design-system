# Figma remains the visual source of truth

## Decision

Figma remains the visual source of truth.

## Context

This project translates an existing visual system into developer packages.

## Chosen approach

Originate visual changes in Figma; record source IDs and decisions; synchronize approved outputs through version control. Runtime semantics supplement Figma but do not authorize silent redesign.

## Reason

Design intent and implementation must remain traceable and reviewable.

## Status

Accepted.
