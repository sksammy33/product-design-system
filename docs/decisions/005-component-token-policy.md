# Component-specific token policy

## Decision

Component-specific token policy.

## Context

Some observed component measurements lack equivalent existing tokens.

## Chosen approach

Reuse source tokens where semantically correct. If a value is missing, propose a component-specific token with exact Figma evidence and obtain approval before adding it. Do not round values or invent aliases.

## Reason

Preserve visual fidelity and traceability while allowing deliberate token coverage improvements.

## Status

Policy accepted; individual additions pending.
